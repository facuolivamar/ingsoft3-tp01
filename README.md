# ingsoft3-tp01

TP01 de la materia Ingeniería de Software 3 — UCC.

Este repositorio no tiene código de aplicación: lo que se pone a funcionar acá es el **flujo de
trabajo** con el que un equipo integra cambios. Ramas cortas, Pull Requests, `main` protegida contra
pushes directos, y la entrega versionada con un tag anotado y su release.

La aplicación del semestre se elige en el TP2.

## Instalación

```bash
git clone https://github.com/facuolivamar/ingsoft3-tp01.git
cd ingsoft3-tp01
```

## Documentación del TP

- **[decisiones.md](decisiones.md)** — por qué Git no pudo resolver el conflicto solo, qué problemas
  aparecieron y cómo se resolvieron, y la declaración de uso de IA.
- **[evidencias.md](evidencias.md)** — las cuatro capturas: el push directo rechazado, el aviso de
  conflicto, los marcadores y la release publicada.

Tag [`v1.0.0`](https://github.com/facuolivamar/ingsoft3-tp01/releases/tag/v1.0.0) sobre el commit que
